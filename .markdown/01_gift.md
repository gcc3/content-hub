  
gift
====
  
  
GitHub: [lhypds/git-toolkit](https://github.com/lhypds/git-toolkit)  
  
`gift` is a webhook server for GitHub events, plus a set of Git/GitHub helper  
functions.  
  
`gift serve` starts the server; `gift create` / `gift delete` / `gift list`  
manage hooks. Other helper functions (e.g. listing weekly PRs, recursively  
pulling repos) run with `gift run` or `gift <function-name>`.
